# Priyanshu Sharma | Portfolio

Personal portfolio website showcasing my projects, skills and contact details.

**Live site:** https://priyanshu-710.github.io

## Features
- Responsive single-page layout that works on mobile and desktop
- Dark and light theme toggle, remembered between visits
- Project showcase with live demo and source code links
- Live date and time in the footer
- Smooth scrolling and keyboard-friendly navigation
- Initials fallback when the profile photo is missing

## Tech stack
HTML, CSS, JavaScript. Hosted on GitHub Pages.

## Featured project
**Complaint Management System** (Flask, SQLite, Bootstrap 5): role-based login, hashed passwords, CSRF protection and an admin panel.
[Live app](https://priyanshu8810.pythonanywhere.com) | [Source code](https://github.com/Priyanshu-710/complaint-management-system)

## Project structure
```
index.html   # page content
style.css    # styles and light/dark themes
script.js    # theme toggle, date and time, avatar fallback
profile.jpg  # profile photo
```

## Run locally
No build step needed. Download the files and open `index.html` in a browser.
